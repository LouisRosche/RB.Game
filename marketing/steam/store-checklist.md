# Steam Store Page Checklist — Alchemy Academy

Target: Page live and accepting wishlists by Week 41 (Phase 3 start).
Goal: 7,000 wishlists before launch day.

Research: Steam pages that go live early (6–12 months before launch) collect
significantly more wishlists. Every week without a wishlist button is lost.

---

## Phase 2 (Weeks 21–40): Prepare Assets

### Copywriting
- [ ] **Game name** confirmed: "Alchemy Academy" (check trademark — see business/legal/)
- [ ] **Short description** (≤ 300 chars): captures science + discovery + idle loop
  Draft: *"Brew potions based on real science. Discover 10 recipes hidden in nature's laws. No pay-to-win, no dark patterns — just curiosity, chemistry, and gold."*
- [ ] **Long description** (800–1,500 words):
  - Hook: lead with the science angle (unique positioning vs. other idle games)
  - Feature bullets (5–7): offline growth, transparent odds, real science facts, etc.
  - FAQ section: "Is it pay-to-win?" (no), "How long is the game?" (15–40 hrs first playthrough)
- [ ] **Tags** (up to 20): Idle, Casual, Educational, Alchemy, Crafting, Science, Indie, Singleplayer
- [ ] **Supported languages** at launch: English. Add German + Simplified Chinese post-launch for ~30% revenue each.

### Visual Assets (required before page goes live)
- [ ] **Capsule image** 460×215px — shows Alchemy Academy logo + lab scene, no text
- [ ] **Header capsule** 460×215px
- [ ] **Small capsule** 231×87px
- [ ] **Main capsule** (library) 616×353px
- [ ] **Screenshots** (min 5, aim for 10):
  - Lab overview (full Alchemist-level lab)
  - Potion brewing in progress
  - Recipe discovery moment (celebratory UI)
  - Journal open on a science fact page
  - Leaderboard / social features
  - Transparent odds panel (unique selling point for screenshots)
- [ ] **Trailer** (60–90 seconds):
  - First 10 seconds: hook ("This game teaches you real science through potions")
  - Show full gameplay loop: plant → grow → harvest → brew → discover
  - Show Legendary reveal moment
  - End card: "Wishlist now on Steam"
  - No fake/edited gameplay — Valve will reject

### Technical
- [ ] **Minimum system requirements**: integrated graphics, 4 GB RAM, Win10/macOS 10.14
- [ ] **Supported controllers**: keyboard/mouse + gamepad (Godot has built-in support)
- [ ] **Achievements**: plan 15–20 (include rare ones for dedicated players)
- [ ] **Steam Cloud saves**: enable via Steamworks SDK
- [ ] **Trading cards**: optional, adds visibility in Steam points shop
- [ ] **Content ratings**: fill out IARC questionnaire (should be rated E/PEGI 3)

## Phase 3 (Week 41+): Go Live

### Steamworks Setup
- [ ] Create Steamworks account ($100 one-time fee)
- [ ] Create app in Steamworks → "Coming Soon" state
- [ ] Upload all assets, fill all copy
- [ ] Set a "To be announced" release date initially
- [ ] Submit for review (Valve takes 3–5 business days)
- [ ] Page live → share wishlist link everywhere (Discord, TikTok, Reddit)

### Next Fest (Steam seasonal event)
- [ ] Apply for the Next Fest closest to launch
- [ ] Prepare a **demo build** (15–30 min, polished, separate Steam app ID)
- [ ] Demo should end with a wishlist call-to-action screen
- [ ] Schedule at least one live stream during Next Fest week

### Launch Week
- [ ] Set concrete release date 2–4 weeks in advance
- [ ] Email existing wishlist subscribers (Steam does this automatically)
- [ ] Coordinate TikTok posts for launch week (5 posts that week)
- [ ] Reach out to science/education YouTubers and streamers 3 weeks before
- [ ] Day-of: post launch trailer, respond to every Steam review in first 48 hours
- [ ] Price: $9.99 (research benchmark for this genre/scope)

## Pricing Strategy

| Price | Reasoning |
|-------|-----------|
| $9.99 | Standard for indie idle/casual |
| 10% launch discount for first 7 days | Drives day-1 velocity and reviews |
| Regional pricing | Enable via Steamworks — Brazil, Turkey, India are large markets with low PPP |
| Bundle with future games | Once Alchemy Academy 2 or sequel exists |
