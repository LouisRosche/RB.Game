# Discord Server Setup — Alchemy Academy

Phase 2 go/no-go requires >=200 engaged members.
"Engaged" = at least 1 message/month, not just joined.

Set up the server **before soft launch** so you have a community home from day one.

**Age requirement:** Discord requires all users to be 13 or older. Although
Alchemy Academy targets ages 8-16 on Roblox, the Discord community is limited
to users aged 13+. This must be stated clearly in:
- The Discord server welcome message
- The Roblox game description (where the Discord link appears)
- Any marketing material that links to Discord

This aligns with COPPA requirements. Players under 13 play the game on Roblox
(where Roblox handles age verification) but are not directed to Discord.

## Server Structure

### Categories & Channels

```
📢 ANNOUNCEMENTS
  #announcements        — Updates, patch notes (server admins only)
  #roadmap              — Pinned public roadmap image (update monthly)

🧪 ALCHEMY ACADEMY
  #general              — Main chat
  #screenshots          — Players share Legendary reveals, big earnings
  #recipes-and-tips     — Strategy discussion, ingredient combos
  #bug-reports          — Structured template (see below)
  #suggestions          — Feature requests (add a vote emoji reaction)

🏆 LEADERBOARD
  #top-alchemists       — Manual weekly post: top 10 from in-game leaderboard
  #achievements         — Players post milestone screenshots

🤝 COMMUNITY
  #introductions        — New member welcome (auto-prompted by bot)
  #off-topic            — Anything non-game

👨‍💻 DEV CORNER (visible to all, writable by dev only)
  #dev-log              — Raw progress notes, behind-the-scenes
  #upcoming-features    — Teasers (no release dates until locked in)

🔇 VOICE
  #chill-lab            — Open voice for co-playing sessions
```

## Engagement Tactics (to reach 200 members)

### Week 1–4 (0 → 50 members)
- Post server link in every TikTok bio and video description
- Pin the link in the Roblox game description
- Post in r/roblox with "join our Discord for updates"

### Week 5–8 (50 → 150 members)
- Host a **weekly Legendary challenge**: first person to screenshot a Legendary this week gets "Legendary Brewer" role
- Post **patch notes** in #announcements whenever you update the game
- Respond to every message in #suggestions (even if the answer is "not planned yet")

### Week 9–16 (150 → 200+ members)
- Host a **monthly Q&A** in voice chat or #dev-corner
- Share a dev-log post every Friday (what you built this week, even if small)
- Run a **recipe discovery race**: first person to discover all 10 recipes wins a permanent role
- Cross-promote in other solo dev Discords (r/gamedev's discord, Roblox DevForum)

---

## Moderation

Solo dev reality: you cannot moderate 24/7. Set up:
1. **AutoMod** (Discord native) — filter slurs, spam, invite links
2. **Slow mode** in #general (1 message per 5 seconds) — prevents spam raids
3. **Verification** — require phone-verified Discord accounts to post (reduces bots)
4. Appoint 1–2 trusted community members as volunteer moderators once you reach ~100 members
